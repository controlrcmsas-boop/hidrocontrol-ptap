## Reglas para Generar los Clips sin Gastar Tokens de Más
1. **Un mensaje independiente por clip:** Genera cada clip en un prompt aislado para que el motor visual no mezcle escenas ni alucine continuidad no deseada.
2. **Locución estricta (< 20 palabras):** Respeta el texto exacto entre comillas; está medido para completarse en 8-10 segundos con pausas naturales.
3. **Estilo visual:** Profesional, industrial, nítido, sin estética de fantasía. Equipos reales, gabinetes eléctricos limpios, interfaces SCADA limpias y procesos industriales verosímiles.

## Resumen de Beneficios Reales para Respaldar la Venta

| Beneficio Real | Justificación Técnica Comprobable |
| :--- | :--- |
| **Seguridad de Hardware** | PLC Siemens S7-1200 con lógica cableada e interlocks físicos independientes del software. |
| **Resiliencia Total (Offline)** | El servidor Edge corre Node-RED y base de datos local con *Store & Forward*; no se detiene si no hay internet. |
| **Doble Agente Inteligente** | El agente Cloud analiza grandes volúmenes y transfiere criterio operativo al agente local. |
| **Ciberseguridad Zero-Trust** | Conexión mediante túnel cifrado (Tailscale) sin abrir puertos en el firewall ni requerir IP pública. |
| **Supervisión Ubicua** | SCADA Web responsivo accesible en tiempo real desde cualquier navegador web o smartphone. |
| **Flexibilidad Multi-Proceso** | El software y hardware admiten cualquier lazo de control: nivel, presión, flujo, temperatura, pH, dosificación y secuencias lógicas. |
